## 📋 Checklist pós-geração

Depois de gerar as 12 imagens:

1. **Redimensionar** cada uma de 1024×1024 → **320×320** (o círculo no card do app é 80px, 320 é 4x DPR retina, suficiente). Use [squoosh.app](https://squoosh.app) ou ImageMagick.
2. **Compressar** com [tinypng.com](https://tinypng.com) → target 20-50 KB por arquivo
3. **Salvar** na pasta `dieta-app/images/` com os nomes exatos da seção "Salvar como" de cada prompt
4. **Adicionar** o campo `image: 'nome-do-arquivo.png',` em cada entry de `MARMITA_DEFS` / `DINNER_DEFS` em `dieta-app/data.js`. Exemplo:

   ```js
   { id: 'A', name: 'Marmita A - Frango',
     image: 'marmita-frango.png',   // ← linha nova
     desc: 'Peito de frango grelhado + arroz branco',
     cooked: '160g frango grelhado | ...',
     kcal: 540, p: 52, c: 40, g: 14,
     ingredients: { frango: 215, arroz_branco: 56, alface: 40, pepino: 80 },
     // ...
   },
   ```

5. **Bump versão** em `sw.js` (pra quebrar o cache do service worker) e `?v=` em `index.html`
6. **Hard reload** no browser (Ctrl+Shift+R) e valida que as imagens aparecem no lugar dos emojis no grid de marmitas/jantares

Se alguma imagem não aparecer, o card cai automaticamente no emoji como fallback — o código já é resiliente a 404. Verifica nome do arquivo e caminho.

## 💡 Dica de ouro pra consistência

**Gere todas as 12 na mesma sessão do ChatGPT/Midjourney**. Quando você abre uma nova sessão, o modelo pode interpretar "warm cream-beige linen textile background" de formas ligeiramente diferentes (tons de creme variados, texturas diferentes). Na mesma sessão, o contexto visual é mais estável e o conjunto fica coerente.

Se uma imagem vier com qualquer elemento fora do padrão (bowl preto, fundo escuro, texto na imagem), peça pra regenerar citando especificamente o erro: *"regenerate with white ceramic bowl, not black"* — melhor que começar do zero.
